# FastTTS-app
A rock-solid, functional, and intuitive text-to-speech app.

Feel free to use whichever version of the program you prefer from the ones I’ve presented.\
The functionality of these applications is more or less the same.\
The only differences are the programming language and the system load.

There are plans to write code in various programming languages ​​in the future.

> [!TIP]
> You type in the text, and it speaks. \
> If you need a specific voice: \
> Download the required model(voice), \
> Select a different configuration from the top menu, \
> Point the program to the files, and use it.
